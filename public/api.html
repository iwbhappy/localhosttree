Как обратиться из своего кода

В браузере /api показывает эту страницу. Для JSON используй /api?format=json или заголовок Accept: application/json. Без заголовка Accept также возвращается JSON.

Фильтры: q, status=online|offline, kind=web|service|database, system=true|false, favorites=true|false. Они доступны на /api и /api/ports; /api/health возвращает сведения о сервере.
Подписи и избранное сохраняются через POST /api/ports/:port с JSON {"name":"SafeWay","favorite":true}. Эта страница выполняет только GET-запросы.
